## 3. Topology changes since the P0 handoff

Same machines and ZFS layout. Differences that matter:

- **Consumer** runs on the **host** as `lab-consumer@<incident>.service` (`Restart=always`, `RestartSec=3`). `pg_recvlogical` → `<evidence>/<scenario>/<incident>/db.jsonl`, wal2json format-version 2, no transform.
- **`lab-incident --new`** starts the consumer after creating dirs. **`--open`** refuses if the consumer is down. **`--close`** records flush LSN then stops it.
- **`lab-slot --create/--drop`** must use `-d labdb`. A recreate without the database put the slot in `postgres`; `pg_recvlogical -d labdb` then failed.
- **`${PG_DATA}.pre-zfs` is gone.** Live `SHOW data_directory` is `/var/lib/postgresql/18/main` on `labpool/victim/pgdata`.
- **`lab-reset --tier t*`** now **refuses while PostgreSQL is running**. Stop the cluster first, then reset (it still restarts PG after rollback). Deepest-first child rollback unchanged.

Guest `/tmp` remains `noexec`. Do not drop test binaries there.
