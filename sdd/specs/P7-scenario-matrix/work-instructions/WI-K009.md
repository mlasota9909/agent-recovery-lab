## Objective

Produce the tranche's headline: the cross-scenario R0-vs-R1-vs-R2 comparison and the Arm A vs Arm B vs naive contrast,
computed entirely from the complete results file and the K008 findings — with SC-04 presented as the strongest figure
(the largest R0-vs-R2 gap, where a flat log cannot surface the signal and only the graph+summaries can).

## Background (read before editing)

This is why P7 exists. The comparison holds the model constant and varies the representation across four scenarios of
increasing difficulty. SC-01 proved the harness; SC-02 added the filesystem track and the checkpoint-granularity
penalty; SC-03 showed the single-coordinate trade-off; SC-04 removes the burst so the representation is the only thing
that can succeed. Every number is sourced from committed fields — determinations, refusals, coordinate error,
precision/recall, evidence bytes, real prompt tokens — never from prose. The honest ordering is reported even if it
does not match the hypothesised ordering (Article XVIII): a null or inverted cell is a finding, diagnosed in K008.

## Steps

1. From `results/matrix.jsonl` + the K008 findings, assemble per (scenario, arm, representation): determinations,
   refusals, refusal rate, median coordinate error (where single-coordinate), SC-04 precision/recall, evidence bytes,
   real prompt tokens, replicate agreement (identical-coordinate rate).
2. Build the cross-scenario R0-vs-R1-vs-R2 table and the Arm A vs Arm B vs naive table. Highlight SC-04's R0-vs-R2 gap
   as the headline figure; state the evidence-bytes / token ratio (R2 vs R0) alongside the accuracy/precision result.
3. Emit `logs/review/K009/headline.json` (all values from committed fields) and `logs/review/K009/headline.md` (the
   cross-scenario tables) with an explicit honest-ordering statement per scenario: does the observed R0<R1<R2 (or whatever
   is observed) match the prediction, and if not, point to the K008 diagnosis.
4. Do not over-claim: where N is small or a cell is under-powered, report the replicate agreement / variance rather
   than a point claim; where R0 exceeds the model context and refuses, report it as a finding (cite K008).
5. Commit. Update the checklist row for K009.
