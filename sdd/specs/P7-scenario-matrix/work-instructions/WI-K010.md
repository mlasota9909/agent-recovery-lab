## Objective

Build the tiered, read-only P7 gate that verifies every P7 acceptance criterion, re-verifies every prior contract hash
unchanged and every prior gate green via regression, and write the P7 handoff — without anti-goal inversion.

## Background (read before editing)

The gate is itself under Article XVI: it must not create, modify or delete anything under the evidence root, proven by
`bin/lab-gate-readonly-check`. It prints per-tier totals separately (Article XIII); a single undifferentiated total is
prohibited. Prior contract hashes — `capture-completeness.md`, `representation-interface.md`(+amendment-1),
`arm-b-protocol.md`(+amendment-1), `model-runtime.md`(+amendment-1), and the P7 contracts — must be byte-identical.
The handoff must state that **P8 builds the analysis notebook and figures** — it must not copy
P7's "do not build the analysis" anti-goal forward as if it were P8's instruction (the P1 inversion lesson).

## Steps

1. Write `bin/lab-verify-p7` invoking every P7 criterion check (reusing the task artefacts), printing `TIER M p/n` and
   `TIER A p/n` separately and a combined line, exit 0 only if all pass.
2. Run `bin/lab-gate-readonly-check bin/lab-verify-p7` to prove the gate is read-only over the evidence root.
3. Re-verify all prior gates green via `bin/lab-regression` against pinned fixtures; hash every prior frozen contract
   and compare to the recorded freeze (all byte-identical).
4. Write `docs/P7-architecture-handoff.md` recording: the re-measured throughput + stratified plan; the four scenarios
   with their corpus citations; the matrix completeness (`total_rows == total_planned_runs`, partition); the SC-04
   cross-representation result; the SC-03 trade-off; the residual-refusal diagnoses; the SC-02 checkpoint-gap + FS/DB
   skew finding; and an explicit "P8 builds analysis/figures" statement. Include a machine-readable
   `docs/P7-handoff.json` for the gate to assert on.
5. Assert the handoff has no anti-goal inversion (it does not tell P8 "do not build analysis").
6. Update the constitution's article count reference if needed (still eighteen — P7 adds no article) and note in the
   handoff where Article XIX would come from if this review surfaces a class.
7. Commit. Update the checklist row for K010.

## Negative test (required)

Two-part: (a) temporarily make `bin/lab-verify-p7` write a marker file under the evidence root; assert
`bin/lab-gate-readonly-check` **catches** the write and fails; revert. (b) Insert an anti-goal-inversion sentence into
a scratch handoff ("P8 must not build the analysis"); assert the handoff check catches it; revert. This proves both
the read-only-gate guard and the inversion guard are live.
