## Objective

Build `bin/lab-repr-r2 <incident>`, which produces (a) a causal graph — nodes for sessions, transactions, relations,
rows, files and processes; edges for caused-by, modified, precedes and depends-on — and (b) hierarchical per-window and
per-entity **summaries** rendered from fixed templates over exact aggregates. Both are **deterministic functions of the
ledger** built with **no model in the loop**. This is the representation the research contribution rests on.

## Background

R2 gives a modest model the "read a short summary and follow a graph, not 900 raw lines" advantage — but only if it is
reproducible and honest. Two rules are absolute: (1) no language model participates — edges are computed by fixed rules
and summaries are rendered from fixed string templates with slots filled by exact aggregates (ADR-P5-2, ADR-P5-6); and
(2) every figure in a summary reconciles exactly to the underlying events (ADR-P5-3). Build from the provenance-blind
events only; no principal in any node/edge label or summary. Materialise under `var/repr/<incident>/R2/`.

## Steps

1. Confirm R0 exists and is admissible. Build the graph from the same provenance-blind events:
   - **Nodes:** one per distinct session (blind session id, never the principal), transaction (`xid`), relation, row
     (`natural_key`), file path, and process where present in the ledger.
   - **Edges:** `modified` (transaction -> relation/row/file it changed), `precedes` (event ordering by integer LSN),
     `caused-by` (change -> the transaction/session that emitted it), `depends-on` (derived by fixed rule, e.g. a row
     change depends-on its relation). Every edge endpoint must exist as a node.
2. Render hierarchical summaries from fixed templates over exact aggregates (reuse R1/C5 figures):
   - per-window: e.g. `Window {i} [{lo}..{hi}]: {n_del} DELETE on relation {rel}, {n_ins} INSERT; anomaly {score}.`
   - per-entity: e.g. `Relation {rel}: {n} changes across windows {w0}..{wk}; peak {peak} in window {pw}.`
   Every numeric slot is an exact count from the events; no free text, no model.
3. Write `var/repr/<incident>/R2/graph.json` (nodes+edges, 0444) and `var/repr/<incident>/R2/summaries.jsonl`
   (0444). Canonical ordering (nodes by type then id; edges by (src,dst,type); summaries by window/entity). Compute
   SHA-256 over the canonical concatenation.
4. Emit `var/repr/<incident>/R2/manifest.json`: `event_count` (events represented in the graph), `ledger_event_count`,
   `reconciles=true` iff every summary figure equals the actual event count it claims AND every edge endpoint resolves
   to a node, `provenance_blind`, `built_by_model=false`, `content_hash`, `source_ledger_hash`.
5. Idempotence: second run byte-identical, `changed:false`. The build `commands.log` must contain **no** model
   invocation of any kind.

## Negative test (required)

Two-part, run independently and reverted:
(a) Alter one summary template figure by +1 in a scratch build and run the reconciliation check; assert it reports
`reconciles=false` for that summary.
(b) Add a synthetic edge whose destination node does not exist; assert F004-1 flags the dangling endpoint.
Revert both -> clean.

## Review bundle

Standard five, plus `manifest.json`, the edge-endpoint resolution report, the three sampled-summary recounts, the
two `content_hash` values, and the `commands.log` excerpt showing no model call.

## Operator review checklist

- [ ] Every edge endpoint resolves to a node; graph is a deterministic function of the ledger
- [ ] Every sampled summary figure reconciles exactly to R0 events
- [ ] No model invoked anywhere in the build (`built_by_model=false`, command log clean)
- [ ] Rebuild byte-identical; no principal token in graph or summaries
- [ ] Both negative cases (bad summary figure, dangling edge) were caught, then reverted
