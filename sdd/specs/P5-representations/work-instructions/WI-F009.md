## Objective

Produce the tranche's headline result on the reconciled SC-01 incident: R0, R1 and R2 all answer the recovery-relevant
probes (`PB-4-earliest-anomaly`, `PB-6-candidate-windows`) with an `answer` that **faithfully bounds the true anomaly
window** per the ledger, and R2 presents **materially fewer** `evidence_bytes`/tokens than R0 for those probes — the
R0-vs-R2 contribution delta. Then prove the discrimination negatives: a representation that omits the anomaly window or
leaks a principal is caught (fidelity/blindness are not rubber stamps).

## Background

This is why P5 exists. The faithful-answer check ties the representations to ground truth: the window each returns must
contain the true malicious burst that the P3/P4 pipeline already established for SC-01. The delta check quantifies the
contribution: the same answer, far less evidence, from R2. Read everything from `answer` and `telemetry`, never prose.

## Steps

1. Establish the true SC-01 anomaly window from the ledger/oracle (the window containing the malicious deletion burst
   the P3 analytics flagged). Record its `window_index` and integer LSN bounds.
2. For `PB-4` and `PB-6`, call the interface for R0, R1 and R2. Assert each `answer` bounds/points at the true anomaly
   window (its window/`last_safe_lsn_int` is consistent with the true bounds under integer LSN).
3. From F008 telemetry, assert `R2.evidence_bytes << R0.evidence_bytes` and record the ratio and absolute delta for
   both probes. Present the R0/R1/R2 telemetry as the headline table.
4. Emit `logs/review/F009/headline.json`
   (`{true_window, per_rep:{R0,R1,R2}:{answer_faithful, evidence_bytes, token_estimate}, r0_vs_r2_delta}`) and a
   `headline.md`.
5. Discrimination: reuse the F006 negative machinery to show a dropped-anomaly-window R1 and a principal-leaking R0 are
   rejected as inadmissible, so a representation cannot pass the headline by cheating.

## Negative test (required)

fails for that representation (the faithful-answer check is real, not a pass-through). Revert -> passes. (Complements
the admissibility negatives in F009-3, which cover omission and provenance leak.)
