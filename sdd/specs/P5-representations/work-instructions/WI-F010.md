## Objective

Build `bin/lab-verify-p5`, the tiered acceptance gate for P5, itself read-only over the evidence root (Article XVI).
Re-verify every prior contract hash unchanged, run the P3.1 regression harness green against pinned fixtures, and write
the P5 architecture handoff — without anti-goal inversion.

## Background

This is the tranche gate. It re-derives every P5 criterion mechanically (never reads an implementer narrative), prints
per-tier totals separately (Article XIII), and must not mutate anything under the evidence root (proven by
`bin/lab-gate-readonly-check`). The handoff must correctly state that **P6 builds the Arm B model harness that consumes
this interface** and P7 drives the run matrix — it must NOT copy P5's "do not build Arm B" anti-goal forward as if it
were P6's instruction (the inversion that nearly derailed an earlier tranche).

## Steps

1. Implement `bin/lab-verify-p5` to re-run every P5 acceptance check (AC-P5-01..AC-P5-16) from live artefacts and the
   ledger, each tagged tier M except the handoff record (tier A). Print `TIER M p/n · TIER A p/n · TOTAL`.
2. Re-verify prior contract hashes: read each recorded hash under `logs/review/` and assert byte-identical, explicitly
   including `capture-completeness.md` and `capture-completeness.amendment-1.md`, `results-row.md`,
   `ledger-integrity.md`, `arm-coordinate.md`, and the two P5 contracts.
3. Run all prior gates (`lab-verify`, `-p1`, `-p1.1`, `-p2`, `-p2.1`, `-p3`, `-p3.1`, `-p4`) and
   `bin/lab-regression` against pinned fixtures; assert all green.
4. Run `bin/lab-gate-readonly-check` around `bin/lab-verify-p5` itself; assert the evidence root is byte-identical
   before and after.
5. Write `docs/P5-architecture-handoff.md` with machine-readable front-matter: the three representations and their
   artefact paths, the identical-interface property (parity result), the deterministic-construction property
   (`built_by_model=false`, byte-identical rebuild), the SC-01 R0-vs-R2 evidence-bytes delta, the admissibility verdict
   per representation, and a `next_tranche` block stating P6 builds the Arm B model harness consuming
   `bin/lab-repr-query` and P7 drives R0/R1/R2 across the matrix.

## Negative test (required)

Two parts, run independently and reverted:
(a) Point `bin/lab-verify-p5` at a scratch copy of a representation with a corrupted summary figure; assert the gate
goes red on the reconciliation criterion (the gate re-derives, not trusts).
(b) Write a draft handoff whose `next_tranche` says "do not build Arm B" (the inversion); assert an anti-goal-inversion
lint catches it. Revert both -> gate green, handoff correct.

result, and the parsed handoff front-matter.
