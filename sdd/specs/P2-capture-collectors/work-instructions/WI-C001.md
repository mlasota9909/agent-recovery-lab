## Objective

Freeze the definition of a complete, exactly-once incident ledger before any collector is wired, and record that the
lab is in a valid state to begin P2 capture.

## Background

Every P2 collector and the P3 analytics read a ledger whose shape and completeness rules must be fixed first. The
contract ships in this package at `sdd/specs/P2-capture-collectors/contracts/capture-completeness.md`; C001 installs
it, verifies it is well-formed, hash-freezes it, and gates the tranche on `bin/lab-ready`.

## Steps

1. Confirm the two entry conditions and record their observed values:
   - `set -a; source etc/lab.env; set +a; bin/lab-ready` exits 0. If not, **stop and report** — do not proceed; the
     operator runs `docs/runbook-slot-recovery.md`.
   - `git status --porcelain --untracked-files=all` is empty (clean tree) before you freeze anything.
2. Verify `contracts/capture-completeness.md` is present and well-formed: every table has a header separator row, all
   fenced blocks are balanced, and the six ledger files in §1 match the file names used by the existing collectors
   (`db.jsonl`, `snapshots.json`, `fs_diff.tsv`, `fs_hashes.tsv`, `session.json`, `workload.jsonl`). If a name
   disagrees with what a prior tranche already produces, **stop and report the conflict** — do not silently rename.
3. Confirm the contract does not contradict the frozen P1 `ledger-integrity.md` (no duplicate LSN within an incident;
   ledger LSN range contained by incident open/close). Record the cross-check.
4. Hash-freeze the contract: record its sha256 in `logs/review/C001/contract.sha256` and copy the frozen file to
   `logs/review/C001/capture-completeness.md`.
5. Record the entry gate: capture `bin/lab-ready` JSON output to `logs/review/C001/lab-ready.json`.

## Negative test (required)

Copy the contract to a scratch path, flip one byte, and run `sha256sum -c` against `contract.sha256`. Assert it
reports a mismatch. Confirm the real contract still matches. This proves the freeze detects tampering, not just that
a hash was written.
