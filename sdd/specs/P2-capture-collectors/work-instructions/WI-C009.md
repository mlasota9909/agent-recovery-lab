# WI-C009 — Capture teardown + slot hygiene

## Objective

Ensure that stopping a capture session leaves the slot clean — lag at zero, slot dropped — while the incident ledger
and snapshots remain intact and append-only.

## Background

The P0.1 review found the slot invalidated (`wal_removed`) because a consumer was left down and WAL accumulated. The
teardown path must prevent that recurring: on `lab-capture stop`, once the consumer has drained, the slot is dropped
cleanly (`bin/lab-slot --drop -d labdb`) so no orphaned slot retains WAL. Teardown must never delete or rewrite the
ledger — the evidence outlives the session. Dropping the slot is correct at teardown; **creating** a slot to fix an
invalidated one is never correct (that is the runbook's rollback path).

## Steps

1. Implement teardown, invoked by `bin/lab-capture stop <incident>`:
   - stop the heartbeat writer and snapshot loop;
   - wait (via `bin/lab-barrier`) for the consumer to drain so `confirmed_flush_lsn` reaches the current WAL position
     — i.e. lag → 0;
   - stop the consumer unit;
   - drop the replication slot with `bin/lab-slot --drop -d labdb`;
   - close `session.json` with the close coordinate and a `teardown_ok` boolean.
2. Assert the ledger files (`db.jsonl`, `snapshots.json`, `fs_diff.tsv`, `fs_hashes.tsv`, `workload.jsonl`) are intact
   and unmodified in content after teardown (compare sha256 before/after teardown of the stop step).
3. Idempotence: teardown on an already-torn-down session is a no-op success; it does not error on an absent slot.

## Negative test (required)

Stop the session but **skip the drain barrier** (simulate the P0.1 condition) so the slot would retain WAL, and assert
a hygiene check flags non-zero lag / a still-present slot as a failure. Then run the proper teardown and assert lag 0
and slot dropped. Separately, confirm teardown never calls `lab-slot --create`. A teardown that leaves a retaining
slot, or that "fixes" state by creating a new slot, is a fail.

## Review bundle

Standard five, plus `slot-after-teardown.log`, `ledger-intact.log`.

## Operator review checklist

- [ ] After stop, lag is 0 and the slot is dropped
