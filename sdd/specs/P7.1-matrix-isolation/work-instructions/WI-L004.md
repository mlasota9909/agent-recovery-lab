## Objective

Re-run the SC-02/03/04 matrix cells live under per-incident isolation, scoring against ground truth, and produce a
completeness report that carries a validity partition. Retain — never delete — the prior stub/hollow cells as
superseded predecessors. This is the task that turns the hollow matrix into a real one. **Execute only if L001 recorded
FULL.**

## Background (read before editing)

L002 gives per-incident isolation (a reset of one incident no longer destroys another). L003 gives real verdicts.
SC-03/SC-04 live snapshots were destroyed in P7, so regenerate those incidents once under isolation (new isolated
subtrees; the banked SC-01 is never touched). Read `run-matrix-plan.amendment-1.md` — it is normative for this task:
live-coordinate resolution (A2), completeness + validity partition (A3), supersede-not-delete (A4), real validation
(A5). Reuse `bin/lab-arm-b` and `bin/lab-arm-a` unchanged.

## Steps

1. Regenerate SC-02 (if its cluster is not resumable), SC-03, SC-04 as isolated incidents (L002 path). Record the new
   incident IDs; do not touch the SC-01 subtree.
2. Run the SC-02/03/04 matrix cells (all timing patterns) via the orchestrator with **live** coordinate resolution
   (`resolved_by: live_heartbeat`, measured `skew_ms`) — no `snapshot_first`/`LAB_P7_HOST_COORD` for a cell with a
   live cluster. Score SC-02 through P4 (L003), SC-03/04 through `bin/lab-validate-set`.
3. For every prior P7 stub/hollow cell, record supersession: the new row carries `supersedes:<prior_row_id>`; the prior
   row carries `superseded_by`. If a prior row's raw record is irrecoverable, record it in
   `results/superseded_manifest.json` with its prior cause (`run_failure: target snapshot does not exist`, or
   `stub_validation`). Delete nothing.
4. Emit `logs/review/L004/matrix-completeness.json`: `total_rows == total_planned_runs` over the **full** design AND
   `partition:{determinations,refusals,run_failures,superseded,stub_validations}` with a `cause` on every
   non-determination. Any undiagnosed `run_failure` or any silently removed cell must make the L006 gate fail.
5. Preserve Arm A's 3σ threshold: if SC-02 Arm A again finds no 3σ window, record it as a genuine `run_failure` with
   cause (`no 3-sigma window; max z ~2.13`), not patched.
6. Confirm provenance-blindness across all re-run assembled prompts/representations (Article II).
7. Commit. Update the checklist row for L004.

## Negative test (required)

Drop one `run_failure` (or superseded) row from a scratch copy of `matrix.jsonl` to inflate the determination share,
run the completeness+validity check, and confirm it exits non-zero (`total_rows != total_planned_runs` or an orphaned
`superseded_by` with no retained predecessor) — proving completeness-is-not-validity is enforced (Article XIX). Revert
to PASS. (AC-P7.1-12)
