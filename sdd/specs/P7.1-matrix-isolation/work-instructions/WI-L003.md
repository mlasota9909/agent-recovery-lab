## Objective

Give the new scenarios a real, non-stub verdict against ground truth. SC-02 (single-coordinate) gets an
`oracle-manifest.json` and scores through the **unchanged** P4 restore+validate path. SC-03/SC-04 (set-and-earliest by
design) get a defined set-validation verdict. This closes D2. **Execute only if L001 recorded FULL.**

## Background (read before editing)

D2: SC-02/03/04 had no `oracle-manifest.json`, so `bin/lab-validate` skipped (`restore_verdict=stub`). Read the SC-01
`oracle-manifest.json` (its exact shape: pre-incident file hashes, per-relation row counts, schema DDL) and the P4
`bin/lab-validate` / `restore-report.md` contract. SC-03 is schema damage (staged); SC-04 is stealthy dispersed
corruption — neither collapses to one correct coordinate (that is why P7 coded them `set_and_earliest`), so their
verdict is precision/recall of the identified malicious transaction set plus the earliest-safe bound, not a single
byte-match. Do **not** fork P4; do **not** invent an SC-01 manifest for a different scenario.

## Steps

1. For **SC-02**, generate `oracle-manifest.json` from the pre-injection state captured at generation (file hashes,
   row counts, schema DDL), in the exact SC-01 shape. Wire the SC-02 cell so an Arm A/Arm B determination scores
   through the unchanged `bin/lab-validate`, yielding a verdict in the P4 set (`correct` / `incorrect-safe` /
   `incorrect-corrupt` / `not-recovered`) — never `stub`.
2. For **SC-03/SC-04**, implement `bin/lab-validate-set` (a thin addition, not a P4 fork): given a determination's
   identified malicious set and the scripted ground-truth malicious set, compute precision, recall, the earliest-safe
   LSN bound, and the count of legitimate DML a single-coordinate restore at the determination would sacrifice. Emit a
   defined verdict object; `stub` is not a permitted outcome for a cell that ran.
3. Keep provenance out of both paths (Article II): the malicious-set ground truth is known to the *oracle/scorer*, not
   to the detection path — the scorer reads it, the representation and model never do.
4. Commit. Update the checklist row for L003.
