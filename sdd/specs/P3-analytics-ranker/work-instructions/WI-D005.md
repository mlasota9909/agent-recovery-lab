## Objective

Generate candidate recovery coordinates from the analytics and anomaly output, each conforming exactly to the frozen
`candidate-coordinate.md` schema — integer + text LSN, resolved snapshot, skew, and the deterministic feature scores —
with no provenance field anywhere.

## Background

A candidate is a plausible safe recovery point. D005 proposes candidates around the transition into anomalous
activity (e.g. commit boundaries in the windows leading up to and including the first anomalous window), resolves each
to its filesystem snapshot and skew via `bin/lab-coordinate` (ADR-008), and computes the frozen feature set:
`proximity_to_first_suspicious`, `data_loss_rows`, `consistency_risk`, `anomaly_score`, `ddl_in_window`. All LSN
ordering and the "newest snapshot with LSN ≤ x" resolution use integer `(high<<32)+low` (ADR-P3-5). No `principal`.

## Steps

1. Build `bin/lab-candidates <incident>`: from `anomaly.jsonl` + the ledger's commit boundaries, enumerate candidate
   LSNs (at least: every commit boundary within a window of the first anomalous window). For each, resolve snapshot +
   skew via `bin/lab-coordinate`, compute the five features, and emit one record per `candidate-coordinate.md`.
2. Compute `candidate_id` as a deterministic function of `(incident_id, lsn_int)`.
3. Enforce the schema: validate every emitted record against the contract's field list; fail loud if any provenance
   field appears or any LSN lacks its integer form.
4. Include an explicit ordering test fixture: candidates at LSNs `3/9` and `3/10` must order `3/9 < 3/10` by integer,
   which string comparison gets wrong.

## Negative test (required)

Two faults, each caught then reverted:
1. **String LSN ordering** — swap the integer comparator for a string comparator; assert the `3/9` vs `3/10` fixture
   (D005-3) now orders them wrongly and the test fails. Revert → passes.
2. **Schema breach** — emit a record missing `lsn_int` (or carrying a `principal` field); assert the schema validator
   (D005-1) rejects it. Revert → passes.

## Review bundle

Standard five, plus `candidates.jsonl`, `schema-validate.log`, `lsn-order-fixture.md`.
