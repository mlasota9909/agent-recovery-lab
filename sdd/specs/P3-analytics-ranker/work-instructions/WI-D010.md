## Objective

Build the P3 gate that re-derives every P3 acceptance criterion with per-tier totals, re-verifies every prior
contract hash unchanged (including `capture-completeness.md` byte-identical), confirms all prior gates still green,
and writes a P3 architecture handoff that documents the analytics/ranker and states — correctly — what P4, P5 and P6
do next.

## Background

Each tranche ends in its own tiered gate. D010 mirrors `lab-verify-p2`/`lab-verify-p2.1`. The handoff must avoid the
anti-goal inversion that nearly derailed P1: it must state that **P5 builds the representations R0/R1/R2** and **P6
builds the Arm B model harness**, and must NOT copy P3's "do not build representations/model" anti-goal forward as if
it were P4/P5's instruction. An explicit anti-inversion assertion guards this.

## Steps

1. Build `bin/lab-verify-p3`: run every AC-P3-01..19 check, re-deriving tier-M criteria from live state or committed
   machine-readable artefacts (never prose). Print `TIER M <p>/<n> · TIER A <p>/<n> · TOTAL`, exit non-zero on any
   fail. Invoke as `set -a; source etc/lab.env; set +a; bin/lab-verify-p3`.
2. Re-verify all prior contract hashes unchanged: P0 (3), P1 (2), P2 `capture-completeness.md`, P2.1
   `capture-completeness.amendment-1.md`, and the two P3 contracts. Assert `capture-completeness.md` is byte-identical
   to its P2 hash (Article XV).
3. Re-run `lab-verify` (18/18), `lab-verify-p1` (24/24), `lab-verify-p1.1` (16/16), `lab-verify-p2` (18/18),
   `lab-verify-p2.1` (16/16); assert all green.
4. Write `docs/P3-architecture-handoff.md`: the analytics feature set + window size, the ranker weights version and
   the tie-break rule, the SC-01 Arm-A-vs-naive headline numbers, the provenance-blindness result, and a "next
   tranches" section stating P4 = restore+validation against the chosen coordinate, P5 = representations R0/R1/R2,
   P6 = Arm B model harness. Include a machine-readable `p3-summary.json` the gate asserts on.

## Negative test (required)

Two faults, each caught then reverted:
1. **Gate can go red** — temporarily move one D009 artefact (e.g. `headline.md`) aside; assert `lab-verify-p3` reports
   that criterion FAIL and a reduced TOTAL, exit non-zero. Restore → green.
2. **Anti-goal inversion guard** — edit a scratch copy of the handoff to say "P4/P5 must not build representations";
   assert the anti-inversion check flags it (the handoff must state P5 *builds* R0/R1/R2). Revert → passes.
