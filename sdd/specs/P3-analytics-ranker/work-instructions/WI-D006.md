## Objective

Rank the candidates with a deterministic scoring function of declared weights and tie-breaks, and emit exactly one
`arm-coordinate` record (`arm=arm_a`) with a deterministic, provenance-free rationale and a `selection_inputs` audit
block proving no ground truth was read. Same ledger + same config → byte-identical chosen coordinate.

## Background

Arm A is the reproducible baseline the experiment is measured against (ADR-003, ADR-P3-2). The score is
`Σ wᵢ·featureᵢ` over the frozen candidate feature set, favouring the latest safe candidate before the first
anomalous window with minimal data loss and no consistency risk. Weights live in a versioned config
(`etc/rank-weights.json`, `selector_version` recorded on the output), so the ranker can be retuned without touching
the candidate schema. Tie-break: latest safe integer LSN. The ranker reads candidates only — never provenance, the
injection log, or the oracle optimum.

## Steps

1. Build `bin/lab-rank <incident>`: load `candidates.jsonl`, load `etc/rank-weights.json`, score each candidate, pick
   the max (tie-break latest safe `lsn_int`), and emit one `arm-coordinate` record with `arm=arm_a`,
   `selector_version` = the weights version, `chosen_candidate_id`, a deterministic rationale string, and a
   `selection_inputs` block with `read_injection_log=false`, `read_oracle_optimum=false`, `read_provenance=false`,
   `ledger_view` = the default view name.
2. Make the rationale a deterministic template over the chosen candidate's features (no free-form text, no wall-clock,
   no PID) so two runs are byte-identical.
3. Validate the emitted record against `arm-coordinate.md` and confirm the coordinate fields map onto the results-row
   `recovery_coordinate.*`.
4. Prove determinism: run twice, `diff` → identical.

## Negative test (required)

Two faults, each caught then reverted:
1. **Determinism** — introduce an unstable tie-break (e.g. pick a random max on ties); construct two equal-score
   candidates and assert the two-run `diff` (D006-2) is non-empty. Revert to latest-safe-LSN tie-break → identical.
2. **Weight sensitivity is real** — flip the sign of the data-loss weight to strongly prefer a lossy candidate; assert
   the chosen coordinate changes. This proves the weights actually drive selection (not a hard-coded pick). Revert.
