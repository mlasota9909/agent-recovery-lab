## Objective

Compute the deterministic, provenance-blind derived analytics over the reconciled SC-01 ledger: per-window
change-burst density, per-relation and per-path churn, deletion-volume spikes, and a DDL flag per window. Output is a
machine-readable artefact that D004 (anomaly scoring) and D005 (candidates) consume.

## Background

All analytics read the ledger through `bin/lab-query`'s **default views**, which exclude `principal` (P2 AC-P2-14).
Time is bucketed into fixed windows (window size declared in scenario config). Every metric is a deterministic
function of the ledger: same ledger → byte-identical output. No provenance, no injection log, no oracle optimum.

## Steps

1. Build `bin/lab-analytics <incident>` computing, per fixed time window (integer-LSN bucketed via the heartbeat
   index), all of:
   - **change-burst density**: change records per second in the window;
   - **per-relation churn**: change count per relation;
   - **per-path churn**: filesystem changes per path from `fs_diff`;
   - **deletion-volume spike**: DELETE rows per window (and per relation);
   - **DDL flag**: boolean, true iff a DDL record falls in the window.
2. Write the result as `analytics.jsonl` (one object per window) plus a `windows.json` header recording the window
   size and the LSN/time bounds of each window. Include an `analytics_version` tag.
3. Confirm the code path reads only default (principal-free) views — no query in the tool may reference
   `principal`/`session_user`/`usename`/UID.
4. Prove determinism: run twice, `diff` the two `analytics.jsonl` outputs → identical.

## Negative test (required)

Two faults, each caught then reverted:
1. **Determinism** — introduce a nondeterministic ordering (e.g. `ORDER BY random()` or an unordered dict dump); assert
   the two-run `diff` is non-empty and D003-2 fails. Revert → identical again.
2. **Provenance leak** — point one metric's query at a principal-bearing view; assert the no-principal scan (D003-4)
   fails. Revert → passes.

## Review bundle

Standard five, plus `analytics.jsonl`, `windows.json`, `determinism.diff`, `no-principal-scan.log`.
