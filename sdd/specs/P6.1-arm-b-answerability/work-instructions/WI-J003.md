## Objective

Fix the cause J001 established: broaden the answer grammar to a resolvable locator (window / LSN hex-or-int /
timestamp) and relax the task framing so the recovery task is answerable from each representation's own vocabulary —
byte-identical across R0/R1/R2, refusal still first-class, the guard still binding, the representations untouched.

## Background (read before editing)

Read `arm-b-protocol.amendment-1.md` (frozen in step 1) for the redefined §2 framing and R4 grammar, and the list of
what stays unchanged (R1, R2, R5, R6, R7, R8). The fix lives entirely in the **shared** prompt template and the
extractor — never in `bin/lab-repr-*` and never in a representation's `content`. The single most important constraint:
broadening the grammar must not admit the reference answer. `bin/lab-modelview-guard` still runs on every assembled
input (Article XVII); a locator the model must *choose* is not a pre-computed `answer`/`candidates` structure. Refusal
stays first-class (Article VIII): an empty, ambiguous, or unresolvable locator is a refusal, never a guess.

## Steps

1. Freeze `arm-b-protocol.amendment-1.md` under `contracts/`; hash-record in `logs/review/J003/`. Confirm the base
   `arm-b-protocol.md` H001 hash still verifies (byte-identical).
2. Rebuild the prompt template used by `bin/lab-arm-b-prompt`:
   - relaxed §2 framing: ask for the latest safe point before the damaging activity, named by whichever locator the
     evidence provides (window / LSN in any form / timestamp); state refusal is appropriate only when the evidence does
     not localise a safe point;
   - the answer-format instruction documents the `COORDINATE: <locator> [<locator> …]` / `REFUSAL: <reason>` grammar;
   - **byte-identical across R0/R1/R2 except the interpolated `model_view.content`** (R1). Keep the single guarded
     assembly path: `bin/lab-arm-b-prompt` still calls `bin/lab-modelview-guard` before templating (R2).
3. Rebuild `bin/lab-arm-b-extract` to the amended grammar:
   - parse only the final tagged line;
   - accept `window=<int>`, `lsn=<hex-or-int>`, `ts=<iso8601>`; resolve each via `bin/lab-coordinate` (window→last-safe
     LSN; hex→integer `(high<<32)+low`; integer as-is; ts→nearest safe LSN at/before);
   - multiple locators must resolve consistently (within incident skew) or the outcome is a refusal (ambiguous);
   - no parsable locator / unresolvable / out-of-range / both tags / neither tag → `outcome="refusal"`, `lsn_int=null`,
     raw completion retained; **no guess** substituted, **no re-prompt**.
4. Assemble prompts for R0/R1/R2 for `PB-6-candidate-windows`; diff them; confirm they differ only in `content`
   (AC-P6.1-09). Pipe each assembled `model_view` through `bin/lab-modelview-guard`; all pass and none carry an
   `answer`/`candidates` structure (AC-P6.1-10).
5. Confirm the R0/R1/R2 representation artefacts are byte-identical to their P5/P5.1 close (F002/F003/F004 hashes
   re-verify) — the fix touched no representation (AC-P6.1-12).
6. Provenance sweep: assert no `principal`/`usename`/`session_user`/UID token appears in any assembled prompt
   (AC-P6.1-15).
7. Commit. Update the checklist row for J003.

## Negative test (required)

Two injections, each proving a guardrail survived the broadening. **(a) Answer leak:** splice the reference `answer`
(`candidates:[…]`) from `bin/lab-repr-reference` into a `model_view`, assemble, and confirm `bin/lab-modelview-guard`
refuses it (exit non-zero naming `answer`/`candidates`); remove it and confirm the assembly passes. **(b) Coerced
refusal:** feed `bin/lab-arm-b-extract` a completion whose only tagged line is `REFUSAL: cannot localise` and confirm
the outcome is `refusal` with `lsn_int=null` and **no** substituted coordinate; then confirm no code path re-prompts
after a refusal. Revert. (AC-P6.1-11)
