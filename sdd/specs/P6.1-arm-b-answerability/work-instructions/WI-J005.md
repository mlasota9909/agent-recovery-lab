## Objective

Gate the tranche: run every P6.1 criterion with per-tier totals, re-verify all prior frozen contract hashes, re-derive
`bin/lab-verify-p6` to be consistent with the amendments, record the old→new criterion mapping proving nothing was
weakened, and update the acceptance memo. The gate itself is read-only over evidence (Article XVI).

## Background (read before editing)

`bin/lab-verify-p6.1` must re-derive each AC-P6.1 criterion mechanically (tier M) except the memo (tier A, asserting on
machine-readable fields). It must confirm no frozen contract file was mutated (all prior H001/F001/… hashes re-verify,
including `model-runtime.md` and `arm-b-protocol.md`, whose amendments live in separate files). The criterion mapping
records the two mechanism changes — containment (loopback → private-network-no-egress) and grammar (rigid → resolvable
locator) — and asserts each is a correction/strengthening, never a relaxation.

## Steps

1. Build `bin/lab-verify-p6.1` running AC-P6.1-01..19, each tier-labelled, printing `TIER M p/n` and `TIER A p/n`
   separately and a combined total; exit non-zero on any failure.
2. Re-derive `bin/lab-verify-p6` so its criteria are consistent with the amendments (containment semantics; the grammar;
   the J004 headline as the result of record) — a correction of the check, not a weakening. Record what changed in the
   mapping.
3. Emit `logs/review/J005/criterion-mapping.json`: for every P6 criterion whose mechanism changed, `old`, `new`, and
   `status ∈ {preserved, strengthened}`; assert no entry is `weakened`. Include the containment redefinition (now tests
   egress — strengthened) and the grammar broadening (still admits no answer, refusal preserved — preserved).
4. Re-verify all prior frozen contract hashes (P0..P6, P5.1) byte-identical; capture `logs/review/J005/contract-hashes.txt`.
5. Run `bin/lab-gate-readonly-check` against `bin/lab-verify-p6.1` and `bin/lab-verify-p6`: evidence tree hash
   byte-identical before and after each (Article XVI).
6. Update `docs/p6-acceptance-memo.md`: record the two remediated defects (the null + its diagnosis; the containment
   correction) and set `p6_accepted_only_after: "P6.1"` on a machine-readable field; note the J004 headline as the
   result of record and the prior null as superseded.
7. Commit. Update the checklist row for J005.
