## Objective

Add the constitutional principle behind defect D1 before repairing the code, and correct the note in the P1 handoff
that wrongly claims results rows already record HEAD at evaluate time — so no future agent restores the broken
behaviour on the strength of it.

## Steps

1. Confirm preconditions and record them in `logs/review/X001/preconditions.json`:
   - `set -a; source etc/lab.env; set +a; bin/lab-verify` reports 18/18.
   - `bin/lab-verify-p1` reports 24/24 (if a runner exists; if not, record its absence, do not build it here).
   - the deploy root is a git repo (`git -C /home/mlasota/thesis rev-parse HEAD` succeeds).
2. Append **Article XIV** to `sdd/.specify/memory/constitution.md`, verbatim:

   > **Article XIV — Provenance of record.** Any artefact that records the identity of the code, data or
   > configuration that produced an experimental result must name the exact state that produced it, re-derived at
   > production time. Where that state is versioned, the recorded identity must be the version-control HEAD at
   > production time, and the producer must refuse to emit a result when the tracked tree has uncommitted changes. A
   > provenance field that can name a state other than the one that produced the artefact is a defect regardless of
   > whether it is currently accurate.

   Do not renumber or edit any existing article. If an Article XIV already exists, stop and report — do not overwrite.
3. In `docs/P1-architecture-handoff.md` (and `docs/P0.1-architecture-handoff.md` if the same claim appears there),
   locate the note asserting that per-row `harness_commit` fields "will be whatever HEAD is at evaluate-arm time."
   That statement is false against the shipped code. Correct it to state the actual P1 behaviour (the field was bound
   to `HARNESS_COMMIT_AT_P1_OPEN`) and that X002 makes it HEAD-at-production with a dirty-tree refusal. Add a dated
   `P1.1 X001` annotation. Do not delete the surrounding context; annotate in place. Capture the diff.
4. Do not touch any `bin/` file, any contract, or `lab-evaluate-arm` in this task.
