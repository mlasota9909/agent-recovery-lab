## Objective

Ensure no document or machine-readable field states or implies that experimental runs have happened when they have
not. The 10 incidents / 150 arm runs are a *plan* derived from the throughput measurement; label them as such and
state explicitly that zero arm runs are complete.

## Background

`docs/p1-acceptance-memo.md` presents `total_incidents: 10` and `total_arm_runs: 150` as headline JSON alongside
`restore_stubbed: true`. `docs/sample-size-plan.md` and the throughput artefact carry the same figures. They are
correct as a *plan*; the defect is that they read as completed totals.

## Steps

1. In every document and JSON artefact carrying these figures (`docs/p1-acceptance-memo.md`,
   `docs/sample-size-plan.md`, `docs/throughput.json` or equivalent), rename the planning counts to unambiguous keys:
   `planned_incidents`, `planned_arm_runs`, `planned_hours` (keep `worst_case_hours` if present, similarly prefixed
   or clearly planning-scoped). Preserve the arithmetic and the derivation; only the naming and framing change.
2. Add an explicit `completed_arm_runs` field, value **0**, and `completed_incidents`, value **0** (the P1 null run
   produced stub rows only, now quarantined; it is not a completed experimental incident). Where free text describes the
   plan, state plainly that no experimental arm has yet been executed and that these are projections from the
   measured cycle time.
3. Do not alter the measured cycle-time values themselves (`median_generate_s`, `median_evaluate_s`) — those are real
   measurements. Only the count and framing is corrected. If any of them is labelled in a way that implies runs
   scored results, fix that wording too.
4. Keep the changes confined to documentation/JSON artefacts. Touch no `bin/` file and no contract.

## Negative test (required)

Add a scratch line to a copy of the memo reading "150 arm runs completed" and run the X005-3 sweep against that copy.
Assert the sweep FLAGS it. Then confirm the real documents pass the sweep. This proves the sweep detects a completion
overclaim rather than trivially passing.
