# WI-N001 — Freeze contracts, add Article XXI, size the sweep

## Goal
Establish the pre-registered footing BEFORE any data exists: freeze the three P9
contracts, append Article XXI, confirm the model set and scenario scope, and re-measure
throughput so N004 is sized honestly (so the sweep has a measured plan).

## Steps
1. Append Article XXI from `.specify/memory/constitution.amendment-article-XXI.md` to
   `sdd/.specify/memory/constitution.md`; verify article count = 21 with no duplicate number.
2. Freeze the three contracts (model-sweep-plan, statistical-analysis-plan, and one
   reserved contract): compute SHA-256 of each, write `contracts/frozen-hashes.json`,
   and pin those digests in the N004/N005/N008 gate scripts.
3. Record the concrete model set in `runtime/p9-model-set.json`:
   for each of 3 models capture `{alias, family, param_class, tokenizer_id, quantisation}`
   by querying the endpoint's model metadata; one entry MUST equal the P6.1 baseline
   verbatim from the P6.1 runtime record. Refuse (exit non-zero) if fewer than 3, if any
   two share `tokenizer_id`, or if fewer than 2 distinct families.
4. Decide scenario scope: SC-01 mandatory. Re-measure full-cycle time for one Arm-B cell
   (assemble->infer->extract->score) and compute projected wall-clock for
   SC-01-only (45 rows) vs SC-01+SC-02 (90 rows). Record in `runtime/p9-throughput.json`
   and set `scope` accordingly (SC-02 only if it fits the stated week budget).
5. Write ADR `docs/adr/ADR-P9-1-sweep-isolation.md` recording the append+sidecar vs
   schema-amendment decision (prefer sidecar `results/sweep-runs.jsonl`).

## Acceptance tests
- AC-P9-01: prove (by commit/timestamp) that all three contract hashes are frozen and
  that NO sweep-runs row exists yet. Print the three digests.
- Model-set validity: show the 3-model record; assert distinct tokenizer_ids and >=2 families.

## Negative test
- Add a 4th temporary model entry that duplicates an existing `tokenizer_id`; run the
  validator; prove it exits non-zero naming the duplicate. Remove the temp entry.

## Review bundle -> logs/review/N001/
- frozen-hashes.json, p9-model-set.json, p9-throughput.json, the ADR, article-count proof,
  negative-test transcript, per-criterion tier line.
