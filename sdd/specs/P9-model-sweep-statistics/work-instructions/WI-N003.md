# WI-N003 — Interface parity across models + representation artefact hashes

## Goal
Prove the anti-artefact invariant: what a model sees is determined by the REPRESENTATION,
never by the model. This is the check that protects the R0/R1/R2 result from a tokenizer-artefact explanation.

## Steps
1. For each representation R in {R0,R1,R2} and each model M, build the model_view via
   `bin/lab-repr-modelview` and pass it through `bin/lab-modelview-guard`.
2. Assert: for fixed R, the model_view bytes are STRUCTURALLY identical across all M
   (same keys, same ordering, `content` identical for fixed R; only the downstream model
   config differs, never the payload structure). Record a parity report
   `logs/review/N003/interface-parity.json` with a per-(R) cross-model structural digest.
3. Re-assert R0/R1/R2 artefact hashes byte-identical to their P5/P5.1 close (read the
   pinned digests from the P5/P5.1 frozen artefacts; recompute; compare).

## Acceptance tests
- AC-P9-03: cross-model structural digest identical per representation.
- AC-P9-04: R0/R1/R2 artefact hashes equal the P5/P5.1 pinned digests.
- AC-P9-05: guard refuses a spliced reference answer on every model input path.

## Negative test
- Inject a per-model structural field (e.g. a model-specific key) into one model_view;
  prove the parity check flags it and the guard/parity gate goes red. Revert.
