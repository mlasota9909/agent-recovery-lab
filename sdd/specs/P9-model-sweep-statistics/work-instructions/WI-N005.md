# WI-N005 — Pre-registered statistics

## Goal
Turn K=5 rates into sound inference under the FROZEN, pre-registered plan. This guards
against over-claiming on tiny samples.

## Steps
1. FIRST: assert the `statistical-analysis-plan` digest is unchanged AND was frozen before
   the first sweep-runs row (compare frozen-hashes.json timestamp/commit to the earliest
   sweep row). If the plan changed after collection began, REFUSE (Article XXI.2).
2. Load ONLY the active partition from `sweep-runs.jsonl` joined to results rows; carry the
   validity partition alongside every aggregate; provenance-blind view (Article II).
3. Compute, exactly per the plan:
   - determination_rate per (representation x model) with the outcome table.
   - H1: Cochran's Q across R0/R1/R2; pairwise McNemar with Holm correction.
   - H2: per-model bootstrap 95% CI (10,000 resamples, pinned seed) on (R2 - R0) rate.
   - Cliff's delta effect sizes.
4. Select and emit VERBATIM the pre-declared interpretation (plan Section 4) matching the
   observed outcome. Lint the emitted prose: reject universal quantifiers
   ("determines", "proves", "always", "in general") applied to the n=1-scenario claim.
5. Write `thesis/analysis/p9-statistics.json` + a human-readable `p9-statistics.md`, each
   regenerable byte-identical via a recorded command.

## Acceptance tests
- AC-P9-07: plan-drift refusal works (see negative test).
- AC-P9-08: tests + CIs + Cliff's delta + Holm produced; each number regenerates identical.
- AC-P9-09: emitted interpretation matches observed outcome; universal-language lint passes.

## Negative test
- Mutate one value in the statistical-analysis-plan; re-run N005; prove it refuses on the
  digest change (does NOT silently analyse). Revert.
- Inject a universal-quantifier sentence into the interpretation template; prove the lint
  rejects it. Revert.
