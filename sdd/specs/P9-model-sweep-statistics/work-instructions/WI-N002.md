## Goal
Make each model a first-class, contained, reproducible subject. Article X + P6.1
amendment applies PER MODEL — do not assume the P6.1 containment result transfers.

## Steps
1. For each model in `runtime/p9-model-set.json`:
   a. Resolve and record `weights_sha256` (or the endpoint's immutable model digest if
      raw weights are not reachable — record which, and why, per Article XV).
   b. Containment check DURING an actual inference call: assert no public-internet egress
      (private-lab endpoint c220m3:4001 -> gb10a:8000 only), assert the alias is the pinned
      LOCAL alias (a cloud alias e.g. any `*-pro`/vendor alias MUST be refused), assert
      greedy decoding + fixed seed are in effect.
   c. Record a one-shot smoke completion (fixed trivial prompt) to confirm the model
      responds and the guard path is used.
2. Write `runtime/p9-model-verify.json` with per-model {weights digest, egress_ok,
   alias_ok, decoding_ok, smoke_ok}.
