## Objective

Confirm the substrate is in the accepted state P1 assumes, and fix a sentence in the P0.1 handoff that would actively
mislead a future agent.

## Why this task exists

`docs/P0.1-architecture-handoff.md` ends with:

> "P1 must not build: ground-truth oracle, results row schema, analytics, ranking, representations, model harness,
> restore verification, scenario damage logic."

The first two items are **wrong**. They are copied from P0's anti-goals list. The ground-truth oracle and the results
row schema are precisely what P1 exists to build. An agent that reads that line and obeys it will refuse the tranche.
The rest of the sentence is correct and stays.

## Steps

1. Verify preconditions and record observed values:
   - `bin/lab-verify` runs clean. Record the per-tier totals verbatim. Expect `TIER M: 9/9 · TIER A: 9/9`.
   - The three P0 contracts hash-match `logs/review/R007/contracts-unchanged.md`.
   - `bin/lab-slot --check` exits 0 and `bin/lab-consumer status` reports the consumer healthy.
   - `etc/lab.env` is present and sources cleanly; record `PG_VERSION`, `ZPOOL`, `DS_PARENT`, `EVIDENCE_ROOT`,
     `ARCHIVE_ROOT`, `RESULTS_ROOT`, `SLOT_NAME`, `DB_NAME`.
   - `RESULTS_ROOT` exists. If it does not, create it mode 0755 and note it.
2. Correct the handoff. Replace the offending sentence with a corrected paragraph that states plainly that P1 builds
   the ground-truth oracle and the results row contract, and that the remaining items (analytics, ranking,
   representations, model harness, real restore verification, SC-02/03/04 damage logic) remain out of P1's scope.
   Add a dated note recording that W001 made the correction and why.
3. Do **not** edit anything else in the handoff. Do not reformat it. Minimal diff.
4. Record the git commit hash of the harness repo as `HARNESS_COMMIT_AT_P1_OPEN` in `etc/lab.env`. If the deploy root
   is not a git repository, initialise one and commit the current state first — `harness_commit` is a required results
   field and cannot be invented later.

## Negative test (required)

copy. Then confirm it passes against the real, unmodified file. This proves the hash check is actually comparing
content rather than merely existing. Do **not** modify the real contract at any point.
