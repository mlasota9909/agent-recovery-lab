## Objective

Implement `bin/lab-ledger-verify` (the three invariants of `contracts/ledger-integrity.md`) and `bin/lab-barrier` (the
mechanical replacement for the operator instruction "wait for `lab-slot --check` 0 before capture").

## Why this task matters more than it looks

The replication slot lives in `PGDATA` and rewinds on a T1 or T2 reset. The host ledger is append-only and does not.
Whether that produces duplicated or orphaned LSN ranges currently depends on incident-scoping discipline being perfect
across hundreds of unattended runs. Discipline is not a control. These two CLIs are.

## Steps

1. `bin/lab-ledger-verify --incident <id>` asserts:
   - **Idempotency** — no LSN appears more than once within the incident's ledger. Exact match after normalising to
     uppercase `X/YYYYYYYY`.
   - **Containment** — every ledger LSN lies within `[incident_open.lsn, incident_close.lsn]`.
   - **Monotonic non-decrease** — commit LSNs are non-decreasing in file order; equal consecutive values are permitted
     only within one transaction commit.
2. **LSN comparison is numeric**, computed as `(high << 32) + low` from the two hex halves. Never string comparison.
   `3/9` sorts above `3/10` lexically, and that error would silently corrupt every range check. Assert this explicitly
   in a unit case using exactly that pair.
3. Emit the JSON shape given in the contract, enumerating violations capped at the first 20 with a total count. Exit
   `0` clean, `1` violated, `2` missing precondition.
4. Never de-duplicate, repair or normalise away a violation. A duplicate is a hard failure (Article VIII).
5. `bin/lab-barrier [--timeout <s>]`:
   - polls `bin/lab-slot --check` until exit 0, or until `${BARRIER_TIMEOUT_S}` elapses;
   - exits non-zero on timeout, and **never** proceeds on a degraded slot;
   - **must not** sleep a fixed guessed interval — a fixed sleep cannot fail and hides the condition it waits for;
   - emits JSON with attempts, elapsed ms, and the final slot state.
6. If the incident record does not yet exist (W008 creates it), accept a `--open-lsn`/`--close-lsn` pair for testing so
   this task is verifiable before the harness exists. Record that this path is test-only and that the harness always
   passes an incident id.

## Negative test (required)

**The de-duplication temptation.** Construct a ledger with one duplicated LSN, run the verifier, and confirm it exits
non-zero *and* leaves the ledger untouched (hash before and after identical). A verifier that "helpfully" removes the
duplicate would destroy the evidence of a capture defect. Assert both the failure and the non-mutation.

**The barrier that cannot fail.** Temporarily replace the poll with a fixed 1-second sleep in a scratch copy, and
confirm test W004-8 then **passes when it should not** — demonstrating why the fixed sleep is prohibited. Revert, and
confirm W004-8 fails correctly again. Do not commit the scratch variant.
