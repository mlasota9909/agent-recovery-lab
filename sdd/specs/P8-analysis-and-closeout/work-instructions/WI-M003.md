# WI-M003 — Generate result figures

## Goal
Generate FIG-5.1..5.4 from loader output, each regenerable byte-identically.

## Steps
1. Implement `analysis/gen_fig.py` with subcommands fig51..fig54 per the manifest.
2. Pin matplotlib for determinism: fixed dpi, fixed font, sorted inputs, no timestamp in metadata
   (set `metadata={'Date':None}` on savefig or strip it). Output PNG + a .meta.json sidecar with
   source_row_ids + validity_partition.
3. Regenerate each figure twice; assert byte-identical (sha256).

## Artefacts
- analysis/gen_fig.py
- thesis/figures/FIG-5.1.png .. FIG-5.4.png (+ .meta.json each)
- logs/review/M003/regen_hashes.json (two hashes per figure, equal)

## Acceptance
- AC-P8-05: every figure regenerates byte-identically; each carries source row ids + partition.
- AC-P8-06: FIG-5.1 reproduces R2 5/5, R0 1/5, R1 0/5 for SC-01 from the rows.
