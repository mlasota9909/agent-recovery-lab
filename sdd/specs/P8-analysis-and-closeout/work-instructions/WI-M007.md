# WI-M007 — Close-out: backup prefix, reproducibility manifest, ADR/constitution index

## Goal
The reversible tooling fix and the two index/manifest artefacts that make the project reproducible.

## Steps
1. BACKUP PREFIX (reversible): change the repomix backup prefix from `thesis-p1-*` to tranche-neutral
   `thesis-*` in the backup tooling/config. Retain the existing dated backup. After the change, produce
   a fresh backup and assert it is byte-identical (sha256) to repomix-latest.md.
2. REPRO MANIFEST: generate `repro/manifest.json` with model id + quantisation + weights sha256, decoding
   params + seed, git commit, ZFS/PostgreSQL/OS versions, and the results file sha256. A missing REQUIRED
   field is a hard failure.
3. ADR/CONSTITUTION INDEX: generate `docs/INDEX.md` listing all twenty constitutional articles (I-XI base,
   XII-XX remediation) and every ADR file under docs/adr/. Cross-check: every amendment that cites an ADR
   must resolve to an existing file, else fail.
