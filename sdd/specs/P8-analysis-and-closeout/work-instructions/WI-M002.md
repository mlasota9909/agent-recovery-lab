# WI-M002 — Deterministic, provenance-blind analysis loader

## Goal
One loader all figures/tables use. Deterministic, active-partition-only, provenance-blind for
comparison views.

## Steps
1. Implement `analysis/loader.py` exposing:
   - `load_active()` -> dataframe of the 51 active rows with validity_partition + supersession_provenance sidecar.
   - `comparison_view(df)` -> drops `principal`/role and any answer-key coordinate field; keeps
     representation id, evidence_bytes, prompt_tokens, refusal flag, verdict, coord error.
2. Make loading deterministic: sort by (scenario, representation, replicate); no wall-clock in output.
3. `load_active()` must raise if handed a superseded or fixtures row.

## Artefacts
- analysis/loader.py
- logs/review/M002/load_active.json (row count, partition, source_row_ids)
- logs/review/M002/comparison_columns.json (the exact permitted columns)

## Acceptance
- AC-P8-03: 51 active from 116; partition {25,25,1}; injecting a superseded row -> loader refuses.
- AC-P8-04: comparison_view excludes principal; exposing it -> guard fires.

## Negative test
Call comparison_view on a frame that still contains `principal`; assert it raises. Then confirm
load_active() raises when fed a fixtures/ row.
