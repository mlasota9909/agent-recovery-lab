# WI-M001 — Freeze analysis-input contract + figure/table manifest

## Goal
Freeze the two contracts that govern all of P8: which rows are consumable, and every reported
artefact with its source query and regen command.

## Steps
1. Copy sdd/specs/P8-analysis-and-closeout/contracts/analysis-input.md and figure-table-manifest.md
   into force; compute sha256 of each and record in logs/review/M001/hashes.json.
2. Implement `analysis/active_partition.sql` (or .py query) that returns exactly the active rows.
3. Prove the active-partition query returns 51 rows from the 116 physical, partition {25,25,1}.
4. Prove it EXCLUDES a known superseded row id (pick one from the supersession manifest).

## Artefacts
- contracts frozen + hashes.json
- analysis/active_partition.*
- logs/review/M001/partition.json  (active_total, det, ref, fail, superseded_excluded)

## Acceptance

- AC-P8-02: manifest frozen; every entry has source query + regen command; hash recorded.
