## Objective

Land the two new constitutional articles that this tranche exists to satisfy, and produce a written inventory mapping
each P0 defect to the article it violates and the task that repairs it. Cheap, first, and load-bearing: every later
task cites these articles, so they must exist before any repair.

## Why this is a task and not a preamble

The P0 build passed its own suite while containing a boundary hatch and nine self-attested criteria. That happened
because no principle prohibited either. Fixing the two instances without fixing the two gaps in the rules leaves the
class of defect live for P1 through P8. The articles are the durable half of this tranche.

## Steps

1. Append the **entire** content of `sdd/.specify/memory/constitution-amendment-001.md`, below the `---` marker, to
   the end of `sdd/.specify/memory/constitution.md`. Preserve the wording verbatim. Do not renumber existing
   articles. Update the ratification footer to read
   `Ratified 2026-08-17. Amendments: 001 (2026-08-17) — Articles XII, XIII.`
2. Verify the appended articles are numbered XII and XIII and that no existing article number was disturbed.
3. Write `docs/p0-defect-inventory.md` containing one row per finding: finding id, one-line description, the file and
   line reference in the P0 build where it lives, the constitutional article it violates (XII, XIII, or VIII for the
   pre-existing fail-loud requirement), the remediation task id, and the acceptance criterion that will prove the
   repair.
4. For each of the five findings, quote the offending code or output **verbatim** into the inventory, with its file
   path and line numbers, as they stand *before* repair. This is your before-state evidence; R002 through R006 will
   produce the after-state.
5. Do not repair anything in this task. Inventory only.

Confirm the amendment file was not merely referenced but copied: delete a distinctive sentence from Article XII in
your working copy, run R001-2, observe it still passes (it only checks headings), then run a content check for the
phrase `A closed door with a hinge is still a door` and observe that it fails. Restore. This demonstrates that heading
presence alone is insufficient evidence, and that you verified content.
