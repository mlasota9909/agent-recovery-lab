## Objective

Wire each determination's extracted coordinate through the **unchanged** P4 restore+validate path to produce the
4-level verdict, `damage_rows_retained` and `legit_rows_lost`, emit the result as the frozen `arm-coordinate` shape
(`arm=arm_b`, `read_*` all false), and prove the whole harness (assembly for a fixed model_view, extraction, scoring)
is byte-identical on re-run over a recorded completion — isolating model non-determinism from harness non-determinism.

## Background

Arm B does not get its own scorer (ADR-P6-5): it hands the coordinate to the same P4 path Arm A uses, so the two arms
are scored identically and comparably. P6 must not modify P4 — its gate hash must re-verify unchanged (checked in
H010). The harness-determinism proof (AC-P6-12) is the crux of verifying a stochastic subject honestly: given a fixed
completion, everything downstream is deterministic.

## Steps

1. For each determination replicate, pass the extracted coordinate to the unchanged P4 restore+validate path; capture
   the 4-level verdict, `damage_rows_retained`, `legit_rows_lost`. Refusals are not scored (no coordinate) and carry
   `score=null`.
2. Emit the frozen `arm-coordinate` record per determination with `arm=arm_b`, `representation`,
   `selection_inputs.read_injection_log=read_oracle_optimum=read_provenance=false`, `ledger_view=<blind view>`, and the
   H006 rationale. Reject (fail loud) any arm-coordinate with a `read_*` true.
3. Land the verdict + rows into the results row alongside H007 telemetry; carry the shared SC-01 `incident_id` so Arm B
   groups with Arm A (P3) and the representations (P5).
4. **Harness-determinism proof.** Take one recorded completion; run extraction + scoring twice; assert the emitted
   arm-coordinate and the score are byte-identical. (The model is not re-invoked; only the deterministic harness runs.)
5. Confirm the P4 path is untouched: record the P4 scorer's file hash before/after and assert unchanged (full gate-hash
   re-verify is in H010).

## Negative test (required)

Construct a scratch arm-coordinate with `selection_inputs.read_oracle_optimum=true` and feed it to the emitter; assert
it is rejected (the anti-peek rule is enforced, not decorative). Revert -> `read_*` all false, accepted.
