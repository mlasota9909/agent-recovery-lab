## Objective

Build `bin/lab-verify-p6`: the tiered, read-only acceptance gate for P6. It re-derives every AC (tier M mechanically;
the two tier A on machine-readable fields), prints per-tier totals separately, re-verifies every prior contract hash
and gate, runs `bin/lab-regression`, is itself read-only over the evidence root, and writes the P6 handoff — without
anti-goal inversion.

## Background

This is the gate the sceptical operator reads first. The two tier A criteria (replicate characterisation, handoff
record) must assert on machine-readable fields, never prose. Per Article XVI the gate must not mutate anything under the
evidence root; prove it with `bin/lab-gate-readonly-check`. The handoff must state that **P7 builds the run matrix** and
must not copy P6's anti-goals forward as if they were P7's instruction (the P1 inversion lesson).

## Steps

1. `bin/lab-verify-p6` re-runs each AC:
   - Tier M: re-derive from committed artefacts / live state (contract hashes; model pinning fields; the offline proof;
     the single-choke-point scan; prompt parity; extraction determinism; refusal handling; the P4-unchanged hashes;
     the arm-coordinate `read_*` fields; the headline error computed vs the true optimum; the discrimination negatives).
   - Tier A: the replicate agreement fields (AC-P6-13) and the handoff record (AC-P6-19), asserted on machine-readable
     fields.
   - Print `TIER M p/n · TIER A p/n · TOTAL` separately.
2. Re-verify all prior contract hashes unchanged, including `capture-completeness.md`, `representation-interface.md`
   and `representation-interface.amendment-1.md` byte-identical; run each prior gate via `bin/lab-regression` against
   its pinned fixture and confirm green.
3. Prove read-only: run `bin/lab-gate-readonly-check bin/lab-verify-p6` and assert the evidence-root manifest is
   byte-identical before and after.
4. Write `docs/P6-architecture-handoff.md` recording: the pinned model (id/quant/weights hash), the guarded single
   choke point, the refusal path, the real-token-vs-P5-estimate finding, the SC-01 R0-vs-R1-vs-R2 result (from
   `headline.json`), and the explicit statement that **P7 builds the run matrix across SC-01..SC-04**, reusing
   `bin/lab-arm-b` unchanged. Emit a machine-readable `docs/P6-handoff.json` mirror for the tier-A assertion.
5. **Anti-goal-inversion guard:** assert the handoff does not tell P7 to skip Arm B or to avoid running the model;
   P6's anti-goals are P6's, not P7's instruction.

## Negative test (required)

Point one prior gate's regression fixture at a mutated ledger (scratch) and confirm `bin/lab-verify-p6` reports that
prior gate red via regression (the prior-gate re-verification is real). Revert -> all green. Additionally, insert an
anti-goal-inversion sentence ("P7 must not run Arm B") into a scratch handoff and confirm the inversion guard fails;
remove it -> passes.
