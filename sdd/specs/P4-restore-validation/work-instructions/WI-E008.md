## Objective

Prove two integration properties: (1) for Arm A's coordinate, the **real-restore** outcome equals the **P3 oracle's
analytical score** for the same coordinate; and (2) a full restore+validate cycle leaves the victim and evidence store
**byte-identical** (the safety property). These are what certify that P3's analytical scoring and P4's real restore
agree, and that P4 never touched what it must not.

## Background

P3 scored a coordinate analytically (from the ledger, without restoring): damage retained / legit lost were computed
by the oracle. P4 now restores for real and re-derives the same quantities from the restored state. If they disagree,
either the analytical scorer or the restore/validation is wrong — a finding either way, and a blocker for the headline.
Separately, the whole restore path must be read-only w.r.t. victim + evidence (ADR-P4-1); this task builds the shared
manifest helper the rest of the tranche uses and asserts it across a full cycle.

## Steps

1. Build/point to a shared manifest helper `bin/lab-victim-manifest` that hashes the whole-of-victim state (victim
   PGDATA + `labpool/victim/*` dataset content) plus the evidence root into one manifest hash. (E004/E006/E007 already
   call it; formalise it here.)
2. **Agreement (AC-P4-15):** run the full pipeline (`lab-restore` -> `lab-validate` -> `lab-verdict`) for the SC-01
   **Arm A** coordinate. Read `summary.damage_rows_retained` and `legit_rows_lost` from `report.json`. Read the P3
   oracle's analytical score for the same coordinate (from the P3 results row / oracle output). Assert they are equal.
   Record both side by side in `agreement.md`.
3. **Safety (AC-P4-16):** capture the manifest before the cycle and after (including after teardown of the sandbox
   cluster + clone). Assert byte-identical, and assert `report.json`'s `safety.victim_untouched` and
   `evidence_untouched` are both `true`.
4. Tear down the sandbox cluster and clone for this cycle (never the victim) and re-assert the manifest is still
   identical.

## Negative test (required)

Two faults, each caught then reverted: (1) perturb the analytical score input (or the validation) so they disagree by
one row; confirm E008-1 fails — proving the agreement check is real, not tautological. (2) During the cycle, write a
byte into a victim dataset file; confirm E008-2/E008-3 catch it (manifest changes; `victim_untouched=false`). Revert
both -> agreement holds and the victim is untouched.
