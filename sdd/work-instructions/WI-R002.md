# WI-R002 — Build the relaxed extractor

**Task:** R002 · **ACs:** AC-P11-02, AC-P11-03, AC-P11-04 · **Est:** 1.5 days

## Goal
`bin/lab-regrammar` implements the frozen answer grammar: resolves locators to LSNs from the evidence only, accepts a single LSN when all locators name the same event, is deterministic, answer-blind, and representation-symmetric.

## Steps
1. Implement the G2 locator resolvers (`lsn_int`, `lsn_hex`, `ts` at heartbeat granularity, `event_ref`) against the frozen model-visible view for a cell. Never load the oracle optimum or `injection_log.json`.
2. Implement the G3 resolution rule (agree → accept; distinct → refusal_parser; none → refusal_parser; declined → refusal_genuine), recording discarded-locator reasons.
3. Keep the code path identical for R0 and R2 (G4): no `representation` branch.

## Acceptance tests
- **AC-P11-02:** re-parse the same completion + frozen view twice → byte-identical parse.
- **AC-P11-03 (answer-blind):** run the extractor with and without the oracle optimum present in the process environment/inputs; assert the parse is byte-identical AND a taint check confirms the oracle value is never read. **Negative:** wire the extractor to prefer, among distinct LSNs, the one nearest the optimum → the answer-blind guard fires and the build is rejected.
- **AC-P11-04 (symmetry):** **Negative:** add a representation-conditional branch → the parity guard fails closed.

## Review bundle
Two-run determinism diff, the answer-blind taint report + its negative transcript, the symmetry parity proof + its negative transcript.
