# WI-Q001 — Freeze contracts, pre-register, size the sweep

**Task:** Q001 · **ACs:** AC-P10-01 · **Est:** 0.5 day

## Goal
Freeze both P10 contracts, record the Article XXI pre-registration BEFORE any scaling run exists, and set K from a real per-cell cost measurement.

## Steps
1. Copy `contracts/scale-generator.md` and `contracts/scaling-analysis-plan.md` into the frozen set; compute and record SHA-256 of each in `docs/adr/ADR-P10-1-contracts.md`.
2. Record the analysis-plan digest with a UTC timestamp in `logs/review/Q001/preregistration.json`. This timestamp is the Article XXI anchor: Q005 compares it against the first `scaling-runs.jsonl` row mtime and refuses if the plan changed after data began.
3. Measure one real per-cell cost: assemble a 200k R0 model_view (no submission needed for timing the assemble+reset), and time reset t1/t2. Record in `logs/review/Q001/sizing.md`.
4. Decide K (default 5; 3 for 500k/1M allowed) and record with rationale. Compute total planned sweep cell count.

## Acceptance test (AC-P10-01)
- Both digests recorded; `preregistration.json` timestamp exists and predates any file under `results/scaling-runs*`.

## Negative test
- Create a throwaway `scaling-runs.jsonl` with an mtime earlier than the preregistration timestamp; a `bin/lab-prereg-check` MUST report the plan was NOT frozen before data. Delete the throwaway.

## Review bundle
