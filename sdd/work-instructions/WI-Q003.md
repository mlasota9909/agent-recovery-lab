# WI-Q003 — Verify scale integrity and representation parity

**Task:** Q003 · **ACs:** AC-P10-03, AC-P10-04, AC-P10-05 · **Est:** 1 day

## Goal
Prove each padded incident is a valid, exactly-once-reconciled incident whose representations differ only as intended.

## Steps
1. For each scale target, run the P2/P2.1 reconciliation over the padded ledger; assert 0 gaps / 0 duplicates using the xid-keyed bijection.
2. Build R0/R2 (and R1 if in scope) via the frozen P5 rules; assemble the guarded model_view at a fixed scale; assert only `content`/`telemetry` differ across representations.
3. Record canonical_tokens for R0 and R2 at every target into `logs/review/Q003/size-table.md` (this feeds the two-curve figure and AC-P10-11).

## Acceptance tests
- **AC-P10-04:** reconciliation 0/0 on ≥3 targets including 500k. **Negative:** duplicate one padded LSN → duplicate detected.
- **AC-P10-05:** parity holds at a fixed scale. **Negative:** inject a model-specific field into one representation → parity/guard fails.
- **AC-P10-03 (recheck):** optimum still invariant post-build.

## Review bundle
Reconciliation reports, parity diff, `size-table.md`, both negative-test transcripts.
